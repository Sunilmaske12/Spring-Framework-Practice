# Java Spring Framework – Practice Projects

This repository contains a collection of hands-on practice projects developed while learning the Java Spring Framework and its related technologies.

Each folder represents a separate project or exercise covering different concepts of Spring, REST API development, ORM integration, and application architecture.

## 🛠️ Technologies Used

- Java
- Spring Framework
- Spring MVC
- Spring ORM
- Hibernate
- JDBC
- REST APIs
- Maven
- MySQL
- XML-based Spring Configuration
- Annotation-based Configuration

## 📚 Projects and Concepts

| Folder | Description |
|---|---|
| `Spring` | Spring Framework fundamentals and dependency injection |
| `Spring2` | Additional Spring Core practice |
| `SpringMVC` | Spring MVC concepts and web application development |
| `SpringORM` | Spring ORM integration and database operations |
| `SpringORM_XMLConfiguration` | Spring ORM using XML-based configuration |
| `springAOP` | Aspect-Oriented Programming concepts in Spring |
| `REST-API` | REST API development practice |
| `SpringREST-API` | Spring-based REST API development |

## 🎯 Learning Objectives

- Understand Inversion of Control (IoC) and Dependency Injection (DI).
- Work with Spring Beans and ApplicationContext.
- Understand Spring MVC architecture.
- Integrate Spring with Hibernate and relational databases.
- Perform database operations using ORM.
- Understand XML-based and annotation-based configurations.
- Learn Aspect-Oriented Programming (AOP).
- Develop RESTful web services using Spring.

## 🚀 Getting Started

### Prerequisites

- JDK 8 or later (depending on the individual project configuration)
- Apache Maven
- MySQL (for projects requiring database connectivity)
- Eclipse IDE or IntelliJ IDEA

### Running the Projects

1. Clone the repository:

   ```bash
   git clone https://github.com/Sunilmaske12/Spring.git
   ```

2. Open the required project folder in Eclipse or IntelliJ IDEA.

3. Import the project as a Maven project if it contains a `pom.xml`.

4. Configure database connection properties if required.

5. Download Maven dependencies and run the project using the appropriate main class or server configuration.

**Note:** Each folder is an independent practice project and may have its own dependencies and configuration requirements.
